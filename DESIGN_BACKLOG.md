# Plot workspace ideas

Kept for a future design pass; these are suggestions, not implemented behavior.

1. Merge the short plot title strip and plot controls into one header. Keep scale, Investigate, and expand visible, with occasional actions in an overflow menu. Preserve comfortable mouse/touch targets.
2. Review unused Plotly top/right margins while preserving readable axis labels and preventing clipping.

Already applied: remove duplicate long titles in workbench tiles, shorten standalone headings, use an accessible icon-only footer reset, tighten legend spacing, and let bias controls wrap alongside legend items.

Also applied: remove repeated device identity, put sweep/temperature/frequency metadata inline in each plot title, move visible-trace/measurement counts and gesture help into a themed info popover, and shorten the scale control/menu to `lin` and `log`.
